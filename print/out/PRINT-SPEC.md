# 1960 Labs: print spec for the printer

## Files

| File | Use |
|---|---|
| `1960Labs_CEO-Card_85x55_press.pdf` | Business card with crop marks. Page 1 is the front, page 2 the back. |
| `1960Labs_CEO-Card_85x55_bleed.pdf` | The same card at trim + bleed, no marks, for imposition. |
| `1960Labs_Flyer_A5_press.pdf` | A5 flyer with crop marks. Page 1 is the front, page 2 the back. |
| `1960Labs_Flyer_A5_bleed.pdf` | The same flyer at trim + bleed, no marks, for imposition. |

## Business card

- **Trim:** 85 × 55 mm. **Bleed:** 3 mm on all sides. **Safe zone:** 4.5 mm.
- **Printing:** double-sided, 4/4 CMYK, head-to-head (both sides upright).
- **Stock:** 400–450 gsm uncoated or silk. Matte lamination on both sides keeps the black panel from scuffing.

## Flyer

- **Trim:** A5, 148 × 210 mm. **Bleed:** 3 mm on all sides. **Safe zone:** 10 mm.
- **Printing:** double-sided, 4/4 CMYK, head-to-head.
- **Stock:** 300–350 gsm silk, or 250 gsm with matte lamination.

## Colour

All artwork is vector CMYK. There are no images or RGB elements.

| Colour | CMYK |
|---|---|
| Rich black (large areas) | C60 M40 Y40 K100 (240% total ink) |
| Black text | K100 |
| Signal blue | C92 M88 Y0 K0. Match to Pantone 2736 C if printing with a spot colour. |
| Greys | K tints only |

- **Fonts:** Inter Tight and JetBrains Mono, embedded as subsets. Smallest type is 6 pt.
- **Lines:** 0.25 pt minimum.
- **QR code:** 25 mm with a 4-module quiet zone. It opens an email to work@1960labs.com.

Please send a hard proof before the full run if time allows. The blue on screen previews looks more violet than it will on paper.
